Lucky Swap — Minecraft 1.19.3 Fabric

- Gives every online player one real lucky:lucky_block every 10 seconds.
- Swaps online player locations every 10 minutes.
- Announces 3, 2, 1 before the swap.
- Drops the block if inventory is full.

Requires Java 17, Fabric Loader, Fabric API 1.19.3, and Lucky Block Fabric 1.19.3.
Build with: gradle build
Output: build/libs/lucky-swap-1.1.0.jar
